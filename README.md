# spy_games_content

Контент (наборы локаций) для приложения «Шпион». Тянется в рантайме по raw-URL
(без токена → репо публичный), обновляется без релиза App Store.

## Структура
- `Content/Sets/manifest.json` — версия пула + список наборов по языкам с их `version`.
- `Content/Sets/<lang>/<id>.json` — сами наборы (`ru/`, `en/`).

## Как обновить контент
1. Правишь/добавляешь `Content/Sets/<lang>/<id>.json` (формат — как в приложении).
2. В `manifest.json`: у изменённого набора **увеличь `version`**; для нового — добавь запись
   `{"id","lang","file":"<lang>/<id>.json","version":1}`; удаляешь — убери запись
   (у пользователей набор пропадёт при следующем онлайн-обновлении).
3. Коммит в `main`. Приложение подхватит при следующем запуске.
